## Mason's Library 
Library mod for other NeoForge mods I might make. Right now it's primarily to make the most tedious things easier, like registries and data stuff.

Contains:
* Registry suppliers for nicer-looking object registration
* More concise methods for data gen providers (recipes, block states, etc.)
* Builder classes for complex item data (tool tiers, armor stats)

You are free to use this in your own mods, but keep in mind that like any library mod, this might not fit your exact needs. 
I'm designing this in a way to fit my conventions for mod development.
